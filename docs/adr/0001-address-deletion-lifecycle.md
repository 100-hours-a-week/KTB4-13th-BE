# ADR-0001: 주소지 삭제 생명주기

## 결정

주소지 삭제는 기존 행을 보존하고 `EntityStatus.DELETED`로 전이하는 소프트 삭제로 처리한다. 삭제 대상이 기본 배송지이면 같은 트랜잭션에서 `created_at DESC`, `id DESC` 순으로 선택한 활성 주소지를 기본 배송지로 승격한다.

## 이유

현재 주소지 모델이 공통 상태 생명주기를 제공하고, 주소지 삭제가 주문 시점의 `order_addresses` 스냅샷을 변경해서는 안 되기 때문이다. 물리 삭제나 별도 `deleted_at` 컬럼 없이 기존 상태 전이와 활성 조건 조회를 재사용한다.

## 결과

- 삭제된 주소지는 목록·수정·기본 배송지 지정 대상에서 제외한다.
- 마지막 활성 주소지도 삭제할 수 있으며, 이후 기본 배송지는 없다.
- 복구 API와 물리 삭제는 제공하지 않는다.
