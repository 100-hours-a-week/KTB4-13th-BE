# ADR-0002: 장바구니 비예약과 결제 시 재고 차감

## 결정

장바구니 상품 추가·수량 변경과 주문 생성은 상품별 현재 가용 재고를 검증하되 재고를 예약하거나 차감하지 않는다. 결제 확정 시 재고를 원자적으로 다시 검증·차감하며, 재고가 부족하면 결제를 확정하지 않는다. 부분 주문과 백오더는 허용하지 않는다.

장바구니에 저장한 수량은 재고 감소만으로 자동 보정하거나 삭제하지 않는다. 결제 실패·취소·환불 뒤 재고 복구 기준과 처리 시점은 결제 기능에서 결정한다.

## 이유

장바구니나 결제 전 주문에서 재고를 예약하면 예약 만료·해제와 주문 취소 보상 처리가 추가된다. 요청 시점의 재고 검증은 사용자에게 현재 상태를 안내하지만 구매를 보장하지 않으며, 경쟁 요청의 최종 판정은 결제 확정 시점에 해야 한다.

## 결과

- 수량 범위 `1~500` 검증과 재고 부족 검증을 별도 규칙으로 유지한다.
- `CartItem.applyQuantity()`는 장바구니 상품 수량의 범위와 상태 전이만 담당한다.
- 상품 추가·수량 변경 UseCase는 상품·재고 Port를 통해 현재 가용 재고를 확인한다.
- 재고 부족으로 장바구니 변경이 실패하면 기존 장바구니 상태를 보존한다.
- 주문 생성은 재고를 예약·차감하지 않으며, 결제 확정에서 원자적으로 재검증·차감한다.
- 결제 실패·취소·환불 후 재고 복구는 결제 기능의 별도 정책으로 다룬다.
