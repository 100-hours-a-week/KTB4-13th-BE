# ADR-0003: 공통 엔티티 삭제 생명주기

공통 엔티티의 `ACTIVE/DELETED` 상태는 삭제 여부만 표현하고 삭제 시각을 보존하지 않는다. 이를 nullable `deleted_at` 기반의 공통 삭제 생명주기로 전환해 삭제 이력을 남기고, 업무 상태와 삭제 상태를 분리한다.

## 결정

- `BaseTimeEntity`가 공통 삭제 시각과 활성·삭제·복구 행위를 소유한다.
- `BaseEntity`는 공통 식별자와 JPA 식별자 매핑을 소유한다.
- 기존 도메인 호출부의 `active()`, `delete()`, `isActive()`, `isDeleted()` 이름은 유지한다.
- 일반 조회는 삭제되지 않은 데이터만 대상으로 하며, 삭제된 데이터를 복구해야 하는 조회는 명시적으로 분리한다.
- `CartItem`은 기존 정책대로 삭제된 동일 항목을 다시 추가할 때 기존 행을 복구한다.
- 판매·결제 등 업무 상태가 생기면 삭제 생명주기와 별도 상태로 관리한다.

## 결과

- 공통 `status` 컬럼과 `EntityStatus` 의존을 삭제하고 새 Flyway 마이그레이션으로 전환한다.
- Repository, JPQL, QueryDSL, 테스트 SQL, 인덱스와 UNIQUE 제약을 삭제 시각 기준으로 검토한다.
- 기존 주소지 삭제 결정은 이 ADR로 대체하며, 물리 삭제와 삭제 데이터의 공개 복구는 기본 범위에 포함하지 않는다.
