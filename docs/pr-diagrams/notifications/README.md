# 알림 기반 기능 시퀀스

- `create`: 내부 알림 생성·저장 (#388)
- `poll`: 인증 회원의 최근 20개와 전체 미읽음 개수 조회 (#389)
- `read`: 본인 알림의 잠금 조회와 최초 읽음 시각 유지 (#390)

Archify JSON 원본에서 HTML을 생성했습니다. 각 diagram의 showcase 검사는 9개 모두 통과했고 구성 오류와 경고는 0개입니다. `receipt.json`에 원본과 HTML의 SHA-256과 크기를 기록했습니다. 자동 브라우저 검사는 네 데스크톱 크기에서 통과했습니다.

PR에는 별도로 내보낸 `monochrome.png`를 사용합니다. SVG에 흰 배경과 검은 선·글자를 적용한 뒤 PNG로 렌더링했으며 세 이미지를 직접 확인했습니다. HTML 뷰어는 기본 테마를 지원하고 고정 UI는 영어이며, 다이어그램 설명은 한국어입니다.

이 검증은 다이어그램에 대한 것이며 애플리케이션 테스트나 운영 검증을 대신하지 않습니다.
